# Central da Formatura — Técnico de Enfermagem

## Instalação rápida

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `app.js` e `config.js`.
3. No Supabase, abra **SQL Editor**.
4. Cole todo o conteúdo de `supabase.sql` e execute.
5. No Supabase, vá em **Project Settings > API**.
6. Copie a **Project URL** e a chave **anon/public** para `config.js`.
7. No GitHub: Settings > Pages > Deploy from branch > `main` / root.
8. Abra o endereço do GitHub Pages.

## Regra de votação

- São 8 participantes.
- 5 votos "Aceitar" = aprovado.
- 5 votos "Rejeitar" = rejeitado.
- 4 x 4 ou menos = continua em votação.
- Nova versão de uma decisão aprovada abre nova votação.
- Tópicos arquivados não são apagados.

## Importante

Esta primeira versão usa nome digitado para identificar o voto. Para uso real com 8 pessoas, recomendo a próxima etapa com login/PIN individual no Supabase Auth, para impedir que alguém vote no lugar de outra pessoa.
